# BiliFloat-HUD
BiliFloat HUD 是一款安卓横屏视频悬浮进度条工具，为 B 站等视频应用补上随时可见的播放进度与时间信息。默认适配哔哩哔哩，也可将其他横屏视频应用加入白名单。悬浮 HUD 显示进度线、当前与总时长、倍速、剩余及预计看完时间，展开可看详情；优先用无障碍读取播放器时间，读不到时用本地 ML Kit OCR 识别屏幕，互为备份，并能识别拖动或跳转后立即刷新；基于黑边检测自动校准视频中心与宽度，支持端点自动修整及对齐预设的保存、导入导出与详情内切换；可调透明度、宽度、位置、主题与播放头图标，折叠态点击厚度可调以减少误触；内置分类诊断日志。OCR 仅在本机处理屏幕图像，不存储、不上传。原生 Kotlin，支持 Android 8-15。
